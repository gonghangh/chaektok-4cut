# 📚 책톡네컷 (Chaektok 4-CUTS)

> **책과 함께 나눈 따뜻한 이야기와 소중한 순간들을 4컷 사진에 담는 포토부스 키오스크 시스템**  
> 9:16 터치 키오스크 & 모바일/PC 반응형 웹 지원, 300 DPI 초고화질 출력 최적화  
> 
> 🌐 **온라인 라이브 체험하기**: [https://gonghangh.github.io/chaektok-4cut/](https://gonghangh.github.io/chaektok-4cut/)

![책톡네컷 로고](assets/chaektok_logo.png)

---

## 🌟 주요 기능 (Features)

- **📚 책톡네컷 단독 시그니처 프레임 연동**:
  - 책과 독서의 감성을 담은 4컷 스태거드(Staggered) 지그재그 레이아웃
  - 고품질 투명 오버레이 마스크를 통한 입체적인 프레임 그래픽
  - 사용자 커스텀 프레임 즉시 업로드 지원
- **📸 스마트 웹캠 촬영 엔진**:
  - FHD 1080p 고해상도 웹캠 실시간 스트리밍
  - 좌우 반전(미러 모드) 원터치 토글
  - 카운트다운 타이머 (5초, 8초, 10초) & 음성 카운트다운 ("셋, 둘, 하나")
  - 기계식 카메라 셔터음 및 플래시 애니메이션 효과
  - 마지막 컷 다시 찍기(재촬영) 기능
- **✨ 감성 사진 필터 6종**:
  - 원본 (Natural), 뽀샤시 (Bloom), 흑백 (Classic Mono), 빈티지 서재 (Sepia), 따뜻한 감성 (Warm), 차분한 쿨톤 (Cool Blue)
- **🎨 스티커 & 텍스트 커스텀**:
  - 독서/책 테마 감성 이모지 스티커 (📚, 📖, 💬, ☕, 👓, 🌿 등)
  - 마우스/터치 드래그 앤 드롭으로 자유로운 스티커 배치
  - 오늘의 책톡 퀵 태그 문구 및 직접 입력
- **🖨️ 인쇄 & 저장**:
  - **A4 4장 모아찍기 (2x2)**: A4 1장에 4장을 모아 인쇄하여 가위로 잘라 친구들과 1장씩 나눔 (절취선 가이드 포함)
  - **4x6 포토 인화지**: 300 DPI (1200 x 1800 px) 초고화질 단독 출력
  - 고화질 PNG 이미지 파일 즉시 저장
  - 스마트폰 카메라로 스캔하여 바로 접속하는 오프라인 QR 코드 내장
- **🌐 100% 무설치 정적 웹 & 로컬 키오스크 지원**:
  - GitHub Pages 정적 웹 환경에서 브라우저만으로 100% 동작
  - 로컬 키오스크 운영 시 무설치 경량 PowerShell 웹서버(`server.ps1`) 지원

---

## 🚀 로컬 실행 방법 (Windows)

1. **원클릭 키오스크 실행**:
   - `Start-책톡네컷.bat` 더블클릭
2. **웹 브라우저 접속**:
   - `http://localhost:8890/`
